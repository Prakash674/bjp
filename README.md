# Bihar Jyotipunj Pathshala - Landing Page

A modern, trustworthy, and parent-friendly landing page for Bihar Jyotipunj Pathshala, offering quality education from Pre-School to Class 8.

## Features

- 🎨 **Modern UI/UX Design** - Clean, structured layout with smooth animations
- 📱 **Fully Responsive** - Mobile-first design that works on all devices
- ⚡ **Fast Performance** - Built with Vite for optimal loading speeds
- ♿ **Accessible** - Follows accessibility best practices
- 🎯 **Trust-Building** - Designed to build credibility with parents

## Tech Stack

- **React 18** - Modern React with hooks
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **Vite** - Fast build tool and dev server
- **Lucide React** - Beautiful icon library

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist` folder.

## Customization

### Colors

Edit `tailwind.config.js` to customize the color scheme:
- `school-blue`: Primary blue color
- `school-green`: Secondary green color
- `saffron`: Accent color

### Content

Update the content in each component file to match your school's specific information:
- Contact numbers and emails
- School address
- Testimonials
- Statistics
- Class descriptions

### Images

Replace placeholder content with actual images:
- Hero section background
- Classroom photos
- Student activities
- Campus facilities
